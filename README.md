# 📚 آموزش زبان انگلیسی — فلش‌کارت و خواندن

یک وب‌سایت مدرن، سریع و کاملاً تحت وب برای یادگیری واژگان و مهارت خواندن زبان انگلیسی.

این پروژه ترکیبی از دو ابزار قبلی (**فلش‌کارت** و **خواندن متن**) است که در یک صفحه واحد با هم ادغام شده‌اند و داده‌های هر دو کتاب **زبان عمومی ۱** و **زبان عمومی ۲** را پوشش می‌دهد.

بدون نیاز به نصب، روی موبایل، تبلت و کامپیوتر قابل استفاده است.

---

## ✨ امکانات

### 🎛 وب‌سایت یکپارچه

* دو بخش در یک صفحه با نوار پیمایش بالای صفحه: **فلش‌کارت‌ها** و **متن خواندن**
* انتخاب کتاب (زبان عمومی ۱ / زبان عمومی ۲) مستقل در هر بخش
* تم تاریک/روشن مشترک بین هر دو بخش
* ذخیره خودکار وضعیت (کتاب، درس، کلمه، نشان‌ها) در مرورگر

### 📖 مرور با فلش‌کارت

* نمایش کلمه انگلیسی، تلفظ فارسی و معنی
* برگرداندن کارت با لمس یا کلیک
* جابه‌جایی آسان بین کلمات

### 🎯 مرور چهارگزینه‌ای

* تبدیل واژگان به آزمون‌های سریع چندگزینه‌ای
* نمایش پاسخ صحیح پس از انتخاب گزینه

### 📝 آزمون ارزیابی

* آزمون مستقل برای هر درس/فصل
* سوالات **درست/غلط** و **چهارگزینه‌ای** استخراج‌شده از کتاب زبان عمومی ۲
* نمایش نتیجه نهایی به صورت درصد و امکان بازگشت به سوالات قبلی

### 📕 بخش خواندن (Reading)

* متن انگلیسی هر درس همراه با ترجمه فارسی
* نمایش **جمله‌به‌جمله** (انگلیسی/فارسی) برای متن‌های زبان عمومی ۲
* تلفظ صوتی متن برای درس‌های زبان عمومی ۱
* جستجوی سریع در واژگان هر درس
* امکان نشان‌گذاری کلمات و مشاهده صفحه «کلمات نشان‌شده»
* بخش گرامر برای درس‌های دارای گرامر

### 🔖 نشان‌گذاری کلمات

* ذخیره کلمات مهم یا دشوار
* مشاهده سریع فقط کلمات نشان‌شده

### 🔥 سطح‌بندی واژگان

* دسته‌بندی کلمات به آسان ✨ و سخت 🔥 با امکان فیلتر

### 🔊 تلفظ صوتی

* پخش تلفظ انگلیسی کلمات با استفاده از Text To Speech مرورگر

### 🎵 افکت‌های صوتی

* بازخورد صوتی برای پاسخ صحیح و غلط با قابلیت قطع و وصل صدا

### 🌙 حالت تاریک

* پشتیبانی کامل از Dark Mode با ذخیره خودکار تنظیمات

### 📱 سازگار با موبایل

* طراحی واکنش‌گرا (Responsive) و پشتیبانی از Swipe در فلش‌کارت‌ها

### 🌐 بدون نیاز به سرور

* اجرا با هر سرور استاتیک ساده یا مستقیم از مرورگر
* قابل استفاده به صورت آفلاین (به جز پخش صدا از منابع دوردست)

## ✏️ افزودن درس یا واژگان جدید

### زبان عمومی ۱ — فلش‌کارت

داده‌ها در فایل `data.js` و بخش `lessonsData` قرار دارند:

```javascript
const lessonsData = {
    lesson1: {
        title: "درس ۱",
        words: [
            {
                en: "apple",
                pron: "اَپِل",
                fa: "سیب",
                difficulty: "easy"
            }
        ]
    }
};
```

| فیلد       | توضیح                         |
| ---------- | ----------------------------- |
| en         | کلمه انگلیسی                  |
| pron       | تلفظ فارسی                    |
| fa         | معنی فارسی                    |
| difficulty | سطح دشواری (`easy` یا `hard`) |

### زبان عمومی ۲ — فلش‌کارت

ساختار یکسان است اما در فایل `data-en2.js` و با کلیدهای `u1` تا `u4` (کلید کلید `lessonsData2`):

```javascript
const lessonsData2 = {
    u1: {
        title: "فصل ۱ — Banana Plant and Its Clinical Uses",
        words: [ /* ... */ ]
    }
};
```

### بخش خواندن

متن‌ها در `reading-data-1.js` (`readingLessons1`) و `reading-data-2.js` (`readingLessons2`) قرار دارند:

```javascript
{
    id: 1,
    unit: 1,                      // فقط برای زبان عمومی ۲ (نمایش Unit)
    title: "Banana Plant ...",
    readingSections: [{
        title: "Part A",
        audio: "url.mp4",         // اختیاری
        english: "...",           // متن انگلیسی
        persian: "...",           // ترجمه
        // یا به‌جای آن:
        pairs: [{ en: "...", fa: "..." }]   // نمایش جمله‌به‌جمله
    }],
    vocabulary: [
        { word: "plant", pronunciation: "پلانت", meaning: "گیاه" }
    ],
    grammar: { title: "...", content: "..." }   // اختیاری
}
```

## 📝 افزودن سوالات آزمون

سوالات آزمون در `examData` (زبان ۱) و `examData2` (زبان ۲) با ساختار زیر تعریف می‌شوند:

```javascript
const examData = {
    lesson1: {
        exam1: [
            {
                q: "معنی کلمه apple چیست؟",
                options: ["سیب", "پرتقال", "گلابی", "موز"],
                ans: 0
            }
        ]
    }
};
```

| فیلد    | توضیح                                 |
| ------- | ------------------------------------- |
| q       | متن سوال                              |
| options | گزینه‌ها                              |
| ans     | شماره گزینه صحیح (از صفر شروع می‌شود) |
